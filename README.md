## Requirements

- C++20 (or later)
- Clang / Clang++
- CMake
- Git
- Command-line build and execution via `./build.sh`

## Build Instructions

From a clean checkout of this repository:

```bash
./build.sh
```

This configures the project with CMake (Clang++) and builds the `github_crawler` executable into the `build/` directory.

## Run Instructions

After a successful build:

```bash
./build/github_crawler
```

Expected output (Milestone 0):

```
GitHub Project Crawler - Milestone 0
Hello from Zack Kingston!
```
